Projeto em Destaque – Minha Automação

contacts-android-automation

Appium Python Pytest Allure LLM (DeepSeek) Android Studio

Objetivo: Automatizar o app de contatos do Android utilizando uma IA (LLM – DeepSeek) para acelerar o desenvolvimento dos scripts de teste.

Stack utilizada: Python + Pytest + Appium + Allure + DeepSeek (LLM) + Node.js (Appium Server) + Android Studio.

Arquitetura: Page Object Model (POM), com camada de dados de teste separada, relatórios Allure integrados ao pipeline.

Desafios enfrentados: Sincronização com a IA para gerar scripts precisos; adaptação a diferentes versões do Android; otimização do tempo de execução dos testes.

Resultados: Aceleração significativa no desenvolvimento da suíte de automação (redução de ~40% no tempo de criação de scripts). Validação completa do CRUD do app de contatos. Testes executados em pipeline CI/CD com relatórios Allure.
